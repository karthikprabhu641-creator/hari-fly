# Map image sources

The map card images are optimized WebP derivatives sized to 960 × 540.

- Skyland: NASA Johnson Space Center, Andes mountain clouds, public domain. [Source](https://commons.wikimedia.org/wiki/File:Clouds_surround_the_rugged_peaks_of_the_Andes_mountain_range_(iss074e0791058).jpg)
- Desert Dunes: Bureau of Land Management Utah / Bob Wick, public domain. [Source](https://commons.wikimedia.org/wiki/File:Utah_Dunes_Landscape_-_West_Desert_District.jpg)
- Coral Ocean: Unsplash photo `photo-1546026423-cc4642628d2b`, Unsplash License. [Source image](https://images.unsplash.com/photo-1546026423-cc4642628d2b)
- Volcano: U.S. Geological Survey, "Lava fountain dome 2", public domain. [Source](https://commons.wikimedia.org/wiki/File:Lava_fountain_dome_2.jpg)
- Sunset Valley, Night City, Snowfall, and Jungle: converted from the existing project JPEG assets.
